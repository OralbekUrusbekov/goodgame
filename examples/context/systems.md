# Каталог систем

## Сервис настроек

Существующий API изменения пользовательских настроек использует HTTP POST и JSON body.
SLA чтения настроек: 99-й процентиль не более 400 мс.

## Сервис уведомлений

Сервис принимает команды с идемпотентным ключом события. Гарантированный SLA доставки — до пяти минут.

## Карточный процессинг

Передаёт уникальный идентификатор события, время операции и финальный статус.
