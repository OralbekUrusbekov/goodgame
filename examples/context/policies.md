# Политики безопасности

- Идентификаторы карт запрещено передавать в URL и query-параметрах.
- Все операции изменения состояния должны использовать HTTP POST, PUT или PATCH.
- Каждое изменение пользовательской настройки должно записываться в аудит с субъектом, временем и прежним значением.
- В логах и уведомлениях разрешены только маскированные реквизиты карты.
- Для нового функционала обязательны модель угроз и согласование информационной безопасности.
