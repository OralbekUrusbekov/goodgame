# Сервис пакетных отчётов

## Цель

Пользователь создаёт отчёт и управляет настройками его отображения.

## Идентификаторы

- Идентификатор отчёта содержит от 3 до 9 латинских символов.
- Идентификатор уникален в пределах рабочей области.

## Состояние отчёта

- У отчёта в каждый момент времени ровно один статус.
- Архивная запись хранит одновременно текущий и предыдущий статусы отчёта.

## Настройки интерфейса

- Экран настроек позволяет прочитать и изменить формат отчёта.
- `PUT /report-settings/{reportId}` сохраняет формат отчёта.
- Тело запроса содержит поле `format` со значением `table` или `chart`.

## Ошибки API

- Каждая ошибка содержит обязательные поля `errorCode` и `message`.
- Ответ 400:

```json
{"message":"Некорректный формат"}
```

## Критерии приёмки

1. Если рабочая область пуста, запрос списка отчётов возвращает ноль непустых строк.
2. При создании отчёта система сохраняет запись с идентификатором `AA`.
3. После архивации запись содержит статусы `ready` и `archived` одновременно.
4. Пользователь открывает экран, меняет формат и видит сохранённое значение.
